# Security Policy

## Supported versions

Only the latest version of `NameGuard.ML.Core` published on nuget.org receives security fixes.

## Reporting a vulnerability

**Do not open a public issue.**

Report vulnerabilities privately via GitHub Security Advisories:
https://github.com/encryptedtouhid/NameGuard.ML/security/advisories/new

You should expect an acknowledgement within 7 days. Coordinated disclosure: a fix and advisory will be published once a patch is available.
